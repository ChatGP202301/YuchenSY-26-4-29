How to select a configuration

  1. Match the cartridge format and connection to the intended housing or water purifier.
  2. Confirm cartridge length, supplied dimensions and media construction.
  3. Select the documented weight, micron rating, iodine value, treatment or additive required for the project.
  4. Request a final specification confirmation and OEM quotation before ordering.
