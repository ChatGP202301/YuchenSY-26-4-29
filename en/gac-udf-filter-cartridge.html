How to select a configuration

  1. Send the existing cartridge model or clear photos, body length and diameter, connection type and seal arrangement. Confirm the matching purifier or housing.
  2. Specify the carbon source, filling weight and iodine value (mg/g), and whether acid-washed media is required. Available combinations need model confirmation.
  3. Tell us whether OEM labeling is required, together with order quantity and destination. Carbon source, filling weight, iodine specification, treatment and labeling affect the quotation.
  4. If a specification is unknown, send photos for a compatibility review. Confirm the final model and configuration before ordering; iodine value alone is not a service-life or removal-performance guarantee.
